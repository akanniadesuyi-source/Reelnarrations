How to use ReelNarrator

1. Set up Gemini

Add your own Gemini API key in API Settings. Gemini is used for video understanding and voice features that require it.

2. Upload a video

Choose a video stored on your device. Use content you own or have permission to edit.

3. Select scenes

Auto lets AI select scenes. Manual lets you enter timestamps. Keep scenes chronological so the recap follows the story.

4. Review the narration

Check that the script explains what is happening and matches the selected footage. Edit or regenerate it before making the video.

5. Generate and download

Once the narration is ready, generate the voice and video. Preview the result, then download it to your device.

Why did my job fail?

Common reasons include an invalid API key, provider quota limits, unsupported video files, or a video that is too large. Check the error message and try again when the provider is available.
